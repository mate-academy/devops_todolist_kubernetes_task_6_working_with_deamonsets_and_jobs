Для розгортання виконайте kubectl apply -f daemonset.yml та kubectl apply -f cronjob.yml, після чого перевірте працездатність ресурсів командою kubectl get all -n mateapp. Валідація рішення здійснюється через перегляд логів: для DaemonSet використовуйте kubectl logs -l app=curling -n mateapp, а для CronJob — kubectl logs $(kubectl get pods -n mateapp --sort-by=.metadata.creationTimestamp | grep hello-cronjob | tail -n 1 | awk '{print $1}') -n mateapp.
