# Instructions for Deploying and Validating DaemonSet and CronJob

This guide provides step-by-step instructions on how to deploy the `daemonset.yml` and `cronjob.yml` manifests into the Kubernetes cluster under the `mateapp` namespace, as well as how to validate that both resources are functioning correctly.

---

## 1. Deployment
Apply the manifests to your cluster using the following commands:

Deploy the DaemonSet that sends curl requests to the todoapp service every 5 seconds from each node in the cluster:

```
kubectl apply -f daemonset.yml
```

Deploy the CronJob designed to call the /api/health endpoint every 4 minutes:

```
kubectl apply -f cronjob.yml
```
## 2. Validation
To ensure the solution is successfully deployed and tasks are executed according to the requirements, verify the statuses and logs as detailed below.

### Step 2.1. Validating the DaemonSet
Check that all DaemonSet Pods are successfully up and running:

```
kubectl get pods -n mateapp -l app=todoapp-server
```
Verify the Logs: Pick any of the running DaemonSet pods and view its logs to confirm it regularly triggers a curl command every 5 seconds:

```
kubectl logs -n mateapp todoapp-server --tail=20
```
You should see successful response logs or communication attempts hitting the todoapp ClusterIP service.

### Step 2.2. Validating the CronJob
Verify that the CronJob is correctly registered with the appropriate schedule (*/4 * * * *):

```
kubectl get cronjob todoapp-cronjob -n mateapp
```
Wait for the CronJob to trigger (runs every 4 minutes). Once triggered, check the jobs and pods created by it:

```
kubectl get jobs,pods -n mateapp
```
Completed jobs will appear in the output, adhering to the history limits (up to 10 successful / 5 failed).

Verify the Logs: To check if the /api/health endpoint is actively called, view the logs of a completed pod generated by the CronJob (the pod name will start with todoapp-cronjob-):

```
kubectl logs -n mateapp todoapp-cronjob
```
The log output should display the response from the /api/health endpoint.
