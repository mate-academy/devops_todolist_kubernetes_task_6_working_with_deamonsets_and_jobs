Для розгортання виконайте kubectl apply -f .infrastructure/daemonset.yml та kubectl apply -f .infrastructure/cronjob.yml, після чого перевірте статус ресурсів через kubectl get ds,cj -n mateapp. Для валідації рішень перегляньте логи DaemonSet командою kubectl logs -l app=curling -n mateapp та логи останнього поду CronJob командою kubectl logs $(kubectl get pods -n mateapp --sort-by=.metadata.creationTimestamp | grep hello-cronjob | tail -n 1 | awk '{print $1}') -n mateapp.
